# Inventario SCA

La aplicación es HTML/CSS/JavaScript vanilla y el árbol no contiene manifiestos npm, pip, Maven, Gradle, Composer o NuGet. No hay paquetes de runtime declarados para resolver. Se añadió configuración de Dependabot para revisar semanalmente las acciones de GitHub, que sí son dependencias externas del pipeline.

El checkout no incluye una exportación de Dependabot Alerts ni una ejecución posterior a este cambio. Tras subir la rama, guardar una captura de Security > Dependabot alerts. No presentar cero alertas como resultado verificado hasta revisar esa pantalla.
