Detalle de Observaciones de Cabeceras y Rutas

1. Ausencia de Cabecera X-Frame-Options Medio

Descripción: El servidor web no incluyó la directiva X-Frame-Options, lo que permite que el portal sea renderizado dentro de un elemento <iframe> en un dominio de un atacante (Clickjacking).

Evidencia: Cabecera ausente en respuesta HTTP inicial.

Corrección aplicada: add_header X-Frame-Options "DENY" always; en Nginx.

2. Ausencia de Cabecera X-Content-Type-Options Bajo

Descripción: El navegador podría interpretar archivos estáticos con un tipo MIME diferente al declarado (MIME Sniffing), exponiendo vectores de cross-site scripting si se cargan recursos no confiables.

Corrección aplicada: add_header X-Content-Type-Options "nosniff" always; en Nginx.

3. Fuga de Versión del Servidor (Server Header) Bajo

Descripción: La cabecera Server retorna el valor nginx/1.18.0 (Ubuntu), facilitando a un atacante la identificación de vulnerabilidades específicas para esa versión.

Corrección aplicada: server_tokens off; en Nginx.

4. Ausencia de Tokens Anti-CSRF Bajo

Descripción: El formulario de simulación en /simulate.html no incluye protección contra Cross-Site Request Forgery.

Tratamiento: Riesgo aceptado pedagógicamente para el Lab 3. Se implementará con autenticación, sesiones y roles en el Laboratorio 4.
